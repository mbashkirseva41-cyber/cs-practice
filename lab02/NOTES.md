
Рабочая папка — это место на компьютере, где я меняю файлы.
Индекс — это зона, куда файлы добавляются перед сохранением.
Коммит — это само сохранение изменений в истории.

Различие Git и GitHub: Git — это программа на компьютере, а GitHub — это сайт.
Использованные команды:
git status — показывает состояние файлов в рабочей директории и индексе.
git diff — показывает изменения в файлах, которые ещё не добавлены в индекс.
git diff --staged — показывает изменения, которые уже добавлены в индекс и готовы к коммиту.
Ветки:
Ветка — это указатель на коммит, позволяющий делать параллельную разработку.
При новом коммите ветка автоматически передвигается вперёд на это новое изменение.
Слияние объединяет изменения из разных веток в одну.
